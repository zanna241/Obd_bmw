# V0.9.6.2 GUI LAZY / STARTUP STABILITY

Il log reale si fermava a:
    GUI: init start heap=138076 psram=8077524

quindi il blocco era dentro `gui_init()`, prima di `GUI: HOME ready`.

Questa build cambia la struttura LVGL:
- al boot vengono creati soltanto HEADER, HOME e il piccolo overlay allarmi;
- MOTORE, DPF, ZF8, LIVE, DIAG e GRAFICI vengono creati solo alla prima apertura;
- IMPOSTAZIONI, DISPLAY, TOUCH e WI-FI vengono creati solo alla prima apertura;
- LVGL resta a 64 KiB per non saturare la DRAM statica;
- aggiunti checkpoint seriali prima/dopo ogni fase della costruzione e del primo render;
- restano invariati CAN, ISO-TP, logger, web, deep sleep e wake GPIO18 della 0.9.6.1.

Sequenza seriale attesa:
    GUI: init start ...
    GUI: LVGL initialized ...
    GUI: display+touch objects OK ...
    GUI: header build start ...
    GUI: header build OK ...
    GUI: HOME build start ...
    GUI: HOME build OK ...
    GUI: first render start
    GUI: first render OK
    GUI: HOME ready ...

Alla prima apertura di una pagina:
    GUI: lazy page N start ...
    GUI: lazy page N done ...
